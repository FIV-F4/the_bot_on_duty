# Анализатор JIRA проектов

Самодостаточный анализатор для изучения структуры проектов JIRA и портала Service Desk.

## 📋 Описание

Анализатор принимает на вход две ссылки:
1. **Ссылка на заявку JIRA** - для анализа структуры проекта
2. **Ссылка на Service Desk портал** - для анализа полей создания заявки

И выдает детальный отчет о:
- Названии проекта
- Обязательных полях в системе JIRA с возможными значениями
- Обязательных полях на портале Service Desk
- Заполненных полях в примере заявки с анализом автоматизации

## 🚀 Установка и настройка

### 1. Установка зависимостей

```bash
pip install -r requirements_analyzer.txt
```

### 2. Настройка переменных окружения

Создайте `.env` файл в корне проекта:

```env
JIRA_URL=https://jira.petrovich.tech
JIRA_API_TOKEN=ваш_api_токен
```

**Получение API токена:**
1. Перейдите в [профиль JIRA](https://jira.petrovich.tech/secure/ViewProfile.jspa)
2. Создайте новый API токен
3. Добавьте его в `.env` файл

**Примечание:** Анализатор может работать и без API токена, но функциональность будет ограничена.

## 🔧 Использование

### Быстрый старт

```bash
# Запуск с дефолтными ссылками
python jira_analyzer.py

# Запуск с собственными ссылками
python jira_analyzer.py "https://jira.petrovich.tech/browse/PW-12345" "https://jira.petrovich.tech/servicedesk/customer/portal/31/create/569"
```

### Программное использование

```python
import asyncio
from jira_analyzer import analyze_jira_project

async def main():
    jira_issue_url = "@https://jira.petrovich.tech/browse/PW-20299"
    service_desk_url = "@https://jira.petrovich.tech/servicedesk/customer/portal/31/create/569"
    
    report = await analyze_jira_project(jira_issue_url, service_desk_url)
    print(f"Проект: {report['project_name']}")

asyncio.run(main())
```

## 📊 Формат отчета

Анализатор генерирует два типа отчетов:

### 1. JSON отчет
```json
{
  "analysis_date": "2024-01-15T10:30:00",
  "project_name": "Название проекта",
  "project_key": "PW",
  "system_required_fields": [...],
  "portal_required_fields": [...],
  "filled_fields_example": {...},
  "automation_analysis": {...}
}
```

### 2. Markdown отчет
Удобочитаемый отчет с разбивкой по разделам:
- Название проекта
- Обязательные поля в системе JIRA
- Обязательные поля на портале Service Desk
- Заполненные поля в примере с анализом автоматизации

## 🏗️ Архитектура

### Самодостаточный дизайн
- **Нет внешних зависимостей от проекта** - все необходимые классы и функции включены в файл
- **Локальная конфигурация** - простая конфигурация через переменные окружения
- **Встроенные модели** - все необходимые модели данных определены локально

### Основные компоненты

1. **LocalJiraConfig** - Конфигурация анализатора
2. **LocalJiraClient** - Клиент для работы с JIRA API
3. **LocalJiraIssue** - Модель задачи JIRA
4. **JiraAnalyzer** - Основной класс анализатора

## 🔍 Что анализирует

### 1. Информация о проекте
- Название проекта
- Ключ проекта
- Доступные типы задач

### 2. Обязательные поля системы JIRA
- Поля, обязательные для создания задач
- Возможные значения полей
- Тип поля (строка, список, дата и т.д.)

### 3. Поля портала Service Desk
- Поля, обязательные на веб-форме
- Описание полей
- Возможные значения из выпадающих списков

### 4. Анализ автоматизации
- **Автоматически заполненные поля** - поля, которые система заполняет сама
- **Пользовательские поля** - поля, которые заполняет пользователь
- **Системные поля** - внутренние поля JIRA

## 🐛 Решение проблем

### Ошибки аутентификации
```
❌ Ошибка: 403 Forbidden
💡 Возможно, нужен валидный API токен в .env файле
```
**Решение:** Добавьте корректный `JIRA_API_TOKEN` в `.env` файл.

### Ошибки сети
```
❌ Ошибка: getaddrinfo failed
```
**Решение:** Проверьте подключение к интернету и VPN.

### Заявка не найдена
```
❌ Ошибка: Задача PW-12345 не найдена
```
**Решение:** Убедитесь, что заявка существует и у вас есть доступ к ней.
