# 🚀 JIRA API Тестер

GUI приложение для отправки произвольных HTTP запросов к JIRA API с удобным интерфейсом.

## ✨ Возможности

- 🔐 **Автоматическая авторизация** - использует настройки проекта (Bearer токен)
- 🌐 **Поддержка всех HTTP методов** - GET, POST, PUT, DELETE
- 📝 **JSON редактор** - с подсветкой синтаксиса для тела запросов
- 📊 **Детальные ответы** - статус, заголовки, форматированный JSON
- 📚 **Готовые примеры** - популярные JIRA API запросы
- ⚡ **Быстрый доступ** - сохранение и очистка полей

## 🛠️ Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r jira_api_tester_requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
JIRA_URL=https://jira.petrovich.tech
JIRA_API_TOKEN=ваш_токен_здесь
JIRA_DEFAULT_PROJECT=SCHED
```

### 3. Получение API токена
1. Откройте https://jira.petrovich.tech/secure/ViewProfile.jspa
2. Перейдите в раздел "Personal Access Tokens"
3. Создайте новый токен и скопируйте его в `.env`

### 4. Запуск приложения
```bash
python jira_api_tester.py
```

## 📖 Как пользоваться

### Интерфейс приложения

1. **🔧 Секция конфигурации** - показывает статус подключения к JIRA
2. **📤 Секция запроса**:
   - Выбор HTTP метода (GET, POST, PUT, DELETE)
   - Поле для URL (автоматически подставляется базовый URL)
   - Редактор JSON для тела запроса
3. **📥 Секция ответа** - отображает результат выполнения запроса

### Основные функции

#### 🚀 Отправка запроса
1. Выберите HTTP метод
2. Введите URL (полный или относительный путь)
3. При необходимости введите JSON тело запроса
4. Нажмите "🚀 Отправить запрос"

#### 📋 Использование примеров
1. Нажмите кнопку "📋 Примеры"
2. Выберите нужный пример из вкладок
3. Нажмите "📋 Использовать этот пример"
4. Пример автоматически заполнит поля

#### 🧹 Очистка полей
Нажмите "🧹 Очистить" для сброса всех полей

## 📚 Готовые примеры

Приложение включает готовые примеры для:

### 1. **Получить задачу** (GET)
```
URL: /rest/api/2/issue/SCHED-144766
```

### 2. **Создать задачу** (POST)
```json
{
  "fields": {
    "project": {"key": "SCHED"},
    "summary": "Тестовая задача из API",
    "description": "Создано через JIRA API Тестер", 
    "issuetype": {"name": "Task"}
  }
}
```

### 3. **Получить проекты** (GET)
```
URL: /rest/api/2/project
```

### 4. **Service Desk запрос** (POST)
```json
{
  "serviceDeskId": "55",
  "requestTypeId": "926",
  "requestFieldValues": {
    "summary": "Тест через Service Desk API",
    "description": "Тестовый запрос"
  }
}
```

### 5. **Поиск задач** (POST)
```json
{
  "jql": "project = SCHED AND status != Закрыта",
  "maxResults": 5,
  "fields": ["summary", "status", "assignee"]
}
```

## ⚠️ Устранение проблем

### Конфигурация не загружена
```
❌ Конфигурация не загружена
```
**Решение:** 
- Убедитесь, что файл `.env` находится в корне проекта
- Проверьте правильность переменных `JIRA_URL` и `JIRA_API_TOKEN`

### Ошибка авторизации (401)
```
📡 Ответ: 401 Unauthorized
```
**Решение:**
- Проверьте актуальность API токена
- Пересоздайте токен в личном профиле JIRA

### Ошибка доступа (403)
```
📡 Ответ: 403 Forbidden
```
**Решение:**
- Проверьте права доступа к проекту/операции
- Обратитесь к администратору JIRA за расширением прав

### Неверный JSON
```
Ошибка JSON: Expecting ',' delimiter: line 3 column 5
```
**Решение:**
- Проверьте синтаксис JSON (кавычки, запятые, скобки)
- Используйте онлайн-валидатор JSON

## 🔧 Расширение функционала

### Добавление новых примеров
В файле `jira_api_tester.py` найдите словарь `examples` в методе `_show_examples()` и добавьте новый пример:

```python
"Мой пример": {
    "method": "POST",
    "url": "/rest/api/2/my-endpoint",
    "json": {
        "field": "value"
    }
}
```

### Настройка таймаута
По умолчанию таймаут составляет 30 секунд. Для изменения найдите:
```python
timeout=30
```
